# Data and assets

- [Trajectory examples](../examples/trajectories/) retain the pouring/wiping CSVs and JSON trajectory values. Public JSON metadata replaces workstation-only paths with relative CSV references; unavailable source JSON/video paths are explicitly null. Original metadata copies are backed up outside the public repository. Processing parameters and all trajectory numbers are unchanged.
- [Current figures](../static/media/v162/) contain Figures 1–8 and A.1–A.4 used by v164. The directory name records their source version; the resource-statement update did not redraw them.
- Thirty-four historical figures and the old v155 snapshot were archived outside the published file tree. `static/media/current/` and `static/media/paper/` are not current resources. [Historical hashes](historical_assets.json) identify the archived files; their former paths are provenance, not working links.
- The two `real_*_global.mp4` clips in [experiment media](../static/media/experiments/) are retained real-task footage. They illustrate interaction, not synchronized compensation activation or recovery evidence.
- The retained anonymous manuscript is v164. Its checksum and the figure paths are in [current_manuscript.json](current_manuscript.json). Its download entry is temporarily hidden from the website.
- Full demonstrations, raw evaluation episodes, original weights and large scenes/point clouds are not included.

Analytic fixtures for the new method code are not manuscript experiment data. Website summary values are transcribed from the manuscript, not generated by tests. Manuscripts, images, videos and example data are not automatically covered by the code license.
